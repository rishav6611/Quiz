PYQs ED8 Quiz - Part 3 (iPhone-ready)

How to publish:
1. In your GitHub repository named "Quiz", create a folder named "PYQs-ED8-Part-3".
2. Upload the index.html file and the complete assets folder into that folder.
3. Keep the assets folder alongside index.html. Do not upload only index.html.
4. After GitHub Pages finishes deploying, open:

https://rishav6611.github.io/Quiz/PYQs-ED8-Part-3/

On iPhone:
- Open the link in Safari.
- Tap Share, then "Add to Home Screen" if you want an app-like shortcut.
- Internet is required to load the hosted page and its images the first time; after caching, offline behavior depends on Safari's cache.

All quiz questions, answers, explanations, and embedded figures from the supplied HTML are retained. The embedded images have been moved into separate WebP files to keep index.html below GitHub's per-file size limit.
