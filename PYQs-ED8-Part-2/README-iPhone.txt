PYQs ED8 Quiz - Part 2 (iPhone-ready)

This folder contains:
- index.html
- assets/ (the quiz's embedded images, extracted into separate files to keep the HTML file small)

To add this as the second quiz in your existing GitHub Pages repository:
1. Keep your existing Biochemistry quiz in the repository root as index.html.
2. Create a folder named PYQs-ED8-Part-2 in the repository.
3. Copy this folder's index.html into PYQs-ED8-Part-2/.
4. Copy the entire assets folder into PYQs-ED8-Part-2/assets/ (do not omit any files).
5. Commit and push the changes.

Expected URL:
https://rishav6611.github.io/Quiz/PYQs-ED8-Part-2/

Important:
- Do not upload only index.html; the assets folder is required for the question and solution images.
- This version extracts the embedded images into separate files. This keeps the HTML under GitHub's 100 MB single-file limit.
- Enable GitHub Pages for the repository (Settings > Pages > Deploy from a branch > main > /(root)).
