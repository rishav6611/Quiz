Upload index.html to the ROOT of your GitHub repository (not inside another folder).
Then open Repository Settings > Pages > Deploy from a branch > main > /(root) > Save.
After deployment, open https://rishav6611.github.io/Quiz/ in Safari.

IMPORTANT: This HTML file is approximately 97 MB because it contains embedded quiz content/images. GitHub's browser upload interface may reject files this large. Use Git from your computer to commit and push it. The file is below GitHub's 100 MiB single-file hard limit, but close to it. GitHub Pages will also need to transfer a large file to each device, so the first load may take time and use substantial mobile data.
